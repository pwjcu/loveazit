💑 "같이 쓰기" 켜는 법 (5분, 무료)
  1. console.firebase.google.com → 프로젝트 만들기
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 → 테스트 모드
  3. 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 내 앱 → 웹(</>) 추가 → firebaseConfig 값 복사 (databaseURL 꼭 포함)
  4. index.html 파일 안의 FIREBASE_CONFIG 를 복사한 값으로 바꾸고 다시 업로드
  5. 테스트 모드는 30일 뒤 만료 → Realtime Database의 규칙 탭에서 {"rules":{".read":true,".write":true}} 로 수정
링크를 아는 사람은 볼 수 있으니, 링크는 둘만 알기! 🤫
