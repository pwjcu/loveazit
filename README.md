# 우리 아지트 (loveazit)

커플이 함께 쓰는 디데이·캘린더·추억·한마디·Q&A·리빙룸 웹앱입니다.

## 프로젝트 구조

- `index.html`: 화면, 스타일, 기능이 모두 들어 있는 메인 파일
- 별도 빌드 과정 없이 정적 웹사이트로 실행되는 구조
- 공유 데이터는 Firebase Realtime Database, 오프라인 미리보기는 브라우저 저장소를 사용

## 안전한 로컬 미리보기

로컬 서버 주소 뒤에 `?local-preview=1`을 붙이면 실제 Firebase 데이터에 연결하지 않고 화면을 확인할 수 있습니다.

예: `http://127.0.0.1:4173/?local-preview=1`

## Q&A 공개 방식

1. 각자 자기 이름을 선택해 답변합니다.
2. 제출한 답변은 작성자에게도 바로 잠깁니다.
3. 두 답변이 모두 모이면 각자 공개에 동의합니다.
4. 두 사람의 동의가 모두 저장된 뒤에만 답변이 공개됩니다.

로그인이 없는 구조이므로 이름 선택과 잠금은 커플끼리 사용하는 화면상 확인 절차입니다. 답변 자체를 암호화하거나 사용자를 인증하는 보안 기능은 아닙니다.
