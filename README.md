# 우리 아지트 (loveazit)

커플이 함께 쓰는 디데이·캘린더·추억·한마디·Q&A·리빙룸·운세 웹앱입니다.

## 프로젝트 구조

- `index.html`: 기존 화면, 저장소 연결, 기본 리빙룸 기능
- `assets/world.js`, `assets/pixel-world.js`, `assets/azit.css`: 펫 생활·시네마·텃밭 규칙과 독자 픽셀 타일/소품/상점 화면
- `assets/fortune.js`: 직접 입력하는 프로필, 궁합, 일일 운세, 22장 타로 해설
- `assets/fortune-sync.js`: Firebase 편집 콘텐츠와 AES-GCM 암호화 커플 동기화
- `assets/couple.js`, `assets/couple.css`: 한마디 칠판·비둘기 우체국·72시간 Q&A·특별 질문
- `assets/together.js`, `assets/together.css`: 매일 기분·대화 미션, 누적 기념 도장, 참여 바로가기
- `assets/settings-extra.js`, `assets/settings-extra.css`: 선택 연락처 보관함·캐릭터 꾸미기
- `assets/vendor/`: 버전을 고정한 음양력 변환 라이브러리와 MIT 라이선스
- 별도 빌드 과정 없이 정적 웹사이트로 실행되는 구조
- 공유 데이터는 Firebase Realtime Database, 오프라인 미리보기는 브라우저 저장소를 사용

## 안전한 로컬 미리보기

로컬 서버 주소 뒤에 `?local-preview=1`을 붙이면 실제 Firebase 데이터에 연결하지 않고 화면을 확인할 수 있습니다.

예: `http://127.0.0.1:4173/?local-preview=1`

배포할 때는 `index.html`과 `assets/` 폴더를 함께 올립니다. 별도의 빌드나 API 키 추가는 필요하지 않습니다.

## 일정과 사진 모아두기

- 달력의 **언젠가 함께**에서 날짜 없이 가고 싶은 장소, 하고 싶은 일, 릴스·지도 링크를 저장하고 수정·삭제합니다. 기존 공유 연결을 사용하며 Firebase `wishes`에 실시간 동기화합니다. 내보내기·가져오기에도 포함됩니다.
- 추억은 한 페이지에 게시글 20개씩 표시합니다. 한 번에 사진을 최대 20장 선택하며, 기본값은 선택한 사진을 한 게시글로 묶기입니다. 체크를 풀면 각각의 게시글로 저장합니다.
- 묶음 사진은 첫 사진과 장수로 표시합니다. 누르면 좌우 버튼·방향키·손가락 밀기로 넘깁니다. 게시글 삭제는 해당 묶음 전체를 삭제합니다. 기존 단일 사진도 그대로 표시됩니다.
- 운세 생년월일은 `19950615`처럼 숫자만 입력하면 `1995-06-15`로 자동 정리됩니다. 기존 날짜 검증은 유지합니다.

## 함께 사는 아지트

일반 보상은 한국 날짜 기준 커플 합산 하루 **8하트**까지입니다. 방문·사진·편지·Q&A는 종류별 하루 한 번 2하트, 펫·꽃 케어는 하루 두 번 각 1하트, 취침은 하루 한 번 1하트이며 모두 같은 8하트 한도에 포함됩니다. 기존 잔액은 유지합니다. 계절 선물은 5하트, 연결한 기념일의 50일 달성 보상은 15하트로 줄였습니다. 과거 기념일을 한꺼번에 소급 적립하지 않으며 기념일을 수정하면 새 날짜의 현재 구간부터 계산합니다.

- 기존에 구입한 펫도 기본적으로 거실에 나타납니다. 이동·애칭·친밀도는 기존 `living` 데이터에 저장합니다.
- 펫의 위치와 애니메이션을 각각의 SVG 그룹에 적용해 좌표가 애니메이션에 덮이는 문제를 수정했습니다.
- 쓰다듬기·공놀이·밥주기는 언제든 가능합니다. 친밀도는 1분에 한 번 오르고, 밥주기 하트는 케어가 필요할 때만 지급합니다.
- 펫 침대/하우스, 수조/턴테이블/아케이드, 무드등, 마당 피크닉/온실, 랜턴을 구매·보관·재배치합니다. 같은 자리의 소품은 교체됩니다.
- 기존 4종에 카페·별빛 다락방·코티지·바닷가 테마를 더했습니다. 새 테마도 200하트이며 보유한 테마는 무료로 다시 적용합니다.
- 시네마의 **우리 추억**은 업로드한 단일·묶음 사진을 12초마다 무작위로 상영합니다. 같은 사진이 연속되지 않으며, 더 커진 거실 스크린에 사진을 꽉 채우고 필름 색감·확대·이동·전환 효과를 적용합니다. 확대 화면의 **사진 전체 보기**로 잘린 가장자리까지 볼 수 있습니다. 사진을 외부 AI로 보내거나 별도 영상으로 재생성하지 않습니다. 현재 상영 사진만 불러오며 삭제되거나 읽지 못하는 사진은 제외합니다.
- **작은 풍경**으로 전환하면 기존 자체 SVG 애니메이션 4편을 24초마다 볼 수 있습니다. 사진이 없거나 읽지 못하는 동안에도 이 풍경을 보여줍니다. 빔프로젝터를 누르면 큰 화면이 열리고, 일시정지/다음 장면/기기별 상영 모드를 지원합니다. 동작 줄이기·룸 움직임 쉬기에서는 자동 전환하지 않습니다.
- 텃밭에서 씨앗을 선택합니다. 첫 물주기는 즉시, 이후는 4시간 간격으로 4단계 성장합니다. 기존 작물의 단계와 예약된 케어 시간은 유지됩니다.
- 씨앗은 3하트이며 텃밭 수확은 수확물 2개를 바구니에 넣습니다. 물주기·수확에는 하트를 지급하지 않습니다. 실내 화분은 수확물 1개를 주고 다시 자랍니다. 수확물과 편지·특별 질문 비용은 같은 `living` 트랜잭션으로 처리합니다.
- 룸은 다음 행동 안내·수확 바구니·픽셀 소품·창빛과 시계·성장 단계·펫 표정과 움직임·의상/소품 꾸미기를 보완했습니다. 화면의 동작 줄이기 설정과 키보드 조작을 지원합니다.
- 신규 펫·소품·테마 구매와 펫 상호작용·텃밭 작업은 Firebase transaction으로 처리합니다. 기존 백업에는 신규 생활 데이터도 포함됩니다.

## 운세 콘텐츠의 기준

운세는 대화를 위한 재미용 콘텐츠입니다. 실제 관계 적합성이나 미래를 예측하는 검사가 아닙니다. 각 카드의 펼침 영역에 점수 규칙을 표시하고, 입력하지 않은 테마는 점수와 평균에서 제외합니다.

- 프로필: 양력/음력 생일, 윤달, 태어난 시각 또는 모름, 성별, MBTI, 혈액형, 선택적 만세력 간지. 상대 정보는 동의를 받고 입력합니다.
- 저장: 연결 전에는 `azit-fortune-v1` 브라우저 저장소를 사용합니다. 운세 → 연결하기 → **초대 링크 만들기**에서 한 사람이 링크를 만들어 상대에게 보내고, 상대가 처음 한 번 열면 프로필·일일 운세·타로·선택 연락처를 AES-GCM으로 암호화해 `fortuneRooms/{키 해시}`에 공유합니다. 이후 같은 브라우저에서는 자동 연결합니다. 기존 코드 연결도 유지됩니다.
- 초대 비밀값은 링크의 fragment에만 담아 외부 리소스가 로드되기 전 주소에서 제거하며 서버 요청·Git·일반 백업에는 넣지 않습니다. 링크는 재사용 가능한 접근 수단이므로 두 사람만 보관합니다. 기기 연결 해제는 링크를 만료시키지 않습니다.
- 연결 실패 시 저장된 연결 정보를 지우지 않습니다. 제한된 자동 재시도, 인터넷 복귀/앱 재방문 시 재연결, 수동 재시도를 지원합니다. 다른 공유 공간이나 기존 로컬 정보가 있는 기기에서는 전환을 확인하며, 이전 정보를 초대 공간에 자동 업로드하지 않습니다. 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 초대 링크를 다시 열어야 합니다.
- 달력: [Korean Lunar Calendar 0.4.0](https://github.com/usingsky/korean_lunar_calendar_js)의 한국 음양력/윤달 변환. 앱의 생일 입력은 1900년 이후의 실제 과거/오늘 날짜로 제한합니다.
- 띠: 음력 설 기준 출생연도입니다. 사주 연주의 입춘 기준과 다릅니다.
- 별자리: 양력 월일의 대중적인 별자리 구간입니다. 출생지/정확한 태양 위치를 계산한 점성 차트가 아닙니다.
- 사주: 만세력에서 확인한 연·월·일주(시주는 선택)를 직접 입력합니다. 유효한 60갑자 조합만 허용하고, 겉글자의 오행과 일간 관계를 간단히 설명합니다. 절기·진태양시·야자시·용신·대운을 자동 계산하지 않습니다. 성별·출생시각 자체로 점수를 바꾸지 않습니다.
- MBTI: 4가지 선호 비교와 대화 제안입니다. [Myers-Briggs의 관계 안내](https://asia.themyersbriggs.com/resources/blog/mbti-personality-type-and-relationships/)처럼 유형으로 관계의 성패를 판단하지 않습니다. 혈액형도 성격을 단정하지 않는 놀이 카드로 구성합니다.
- 일일 띠/별자리: 한국 시간 자정 기준, 해당 띠/별자리와 날짜로 고르는 자체 조언입니다. 같은 날에는 새로고침해도 같은 결과를 표시합니다.
- 타로: 메이저 아르카나 22장, 정·역방향 해설. 사람별 하루 한 장을 저장하며 두 사람의 카드가 모이면 타로 궁합이 열립니다. 최근 30일을 보관합니다.
- 기존 「궁합과 미래 사주 분석」 자료에서 입력 확인 → 오행 관계 → 생활 언어의 대화 제안으로 이어지는 구성을 개인 정보와 단정적 예측 없이 일반화했습니다. 이 편집 콘텐츠는 Firebase `fortuneContent/v1`에 한 번 초기화되고 실시간으로 읽으며, 형식 오류나 연결 실패 때는 앱의 동일한 내장 콘텐츠를 사용합니다. 출생 정보는 외부 AI로 전송하지 않습니다.

현재 Firebase 규칙은 로그인 없는 커플용 공개 접근 방식입니다. 운세 본문은 초대 링크의 키가 없으면 해독할 수 없지만, 공개 규칙만으로 삭제 방해까지 막을 수는 없습니다. 불특정 다수에게 공개하기 전에는 Firebase Authentication과 커플별 접근 규칙으로 전환해야 합니다.

## 비둘기 우체국과 선택 연락처

- 한마디 탭의 **우리의 한마디 칠판**은 두 사람의 새 글을 지우기 전까지 차곡차곡 보여줍니다. 새 글에만 분필 효과를 적용하며, **지우고 보관** 또는 **칠판 지우고 보관**은 지우개 효과와 함께 기록으로 옮깁니다. 실제 `notes`는 삭제하지 않습니다. 칠판을 누르면 보관한 글까지 20개씩 읽습니다. 예전 버전의 글은 각 사람의 최근 글만 처음 표시하고, 나머지는 기록에 남깁니다. 보관한 기존 글 대신 더 오래된 글이 다시 나타나지는 않습니다.
- 키보드 입력은 280자까지 분필 미리보기를 지원합니다. 손글씨는 손가락·마우스·펜으로 쓰며 한 획 되돌리기와 지우개를 제공합니다. 작성창의 지우개는 초안만 비우며, 게시된 글의 지우기는 기록으로 보관합니다. 저장 실패 시 초안이 유지되고, 두 사람이 동시에 남기면 각각 별도 기록으로 저장합니다. 칠판과 비둘기 편지는 같은 일일 한마디 보상 한도를 사용합니다.
- 편지는 보낼 때 **1시간~7일** 중 한 번 정한 배달시각을 저장합니다. 새로고침으로 다시 추첨하지 않으며, 도착 후 받는 사람이 봉투를 눌러 엽니다. 발송 뒤 수정은 없고 비행 중인 편지는 사람별 최대 3통입니다.
- 수확물 1개로 남은 시간을 무작위 **15~35%** 줄입니다. 편지당 3번까지 먹일 수 있고, 마지막 5분은 날아옵니다. 실제 비행·도착 상태는 앱을 다시 열 때도 계산합니다. 앱이 닫혀 있을 때 외부 알림을 보내는 기능은 없습니다.
- `living.mailbox`, `living.qaRounds`, `living.pantry`는 기존 커플 생활 저장소에 함께 보관합니다. 편지 봉인과 Q&A 잠금은 화면상 가림이며 사용자 인증이나 암호화 보관함이 아닙니다.
- 설정의 전화번호·카카오톡 ID·비상 연락처는 모두 선택 항목입니다. 기본 화면에서는 가리며, 운세 초대 연결이 되어 있을 때 `fortuneRooms/{해시}/contacts/1`, `contacts/2`에 사람별로 AES-GCM 암호화해 저장합니다. 동시에 저장해도 다른 사람 항목을 덮어쓰지 않습니다. 연결 전에는 해당 브라우저에만 보관하고 일반 앱 백업에는 연락처를 포함하지 않습니다. 표시·복사·전화·연락처 지우기를 지원합니다.

## 검증

로컬 미리보기에서 펫 구매·위치·애칭·케어 보상·재접속, 소품 재배치와 시네마, 씨앗 선택·성장·수확, 운세 입력 검증·한국 윤달 변환·궁합 대칭성·타로 재접속을 브라우저로 확인합니다. 320/375/390/768/1440px와 동작 줄이기도 확인 대상입니다. 실서비스 Firebase 데이터에는 테스트 값을 쓰지 않습니다.

## Q&A 공개 방식

일상·특별 질문을 합쳐 **뽑은 시각부터 72시간에 한 건**입니다. 바로 답변하거나 공개해도 다음 질문이 빨리 열리지 않습니다. 일상 질문은 9개 주제의 54개, 선택형 특별 질문은 6개 주제의 24개로 구성합니다. 특별 질문은 둘 다 성인 확인과 주제 동의 후 12하트 또는 수확물 4개로 뽑습니다. 노골적인 묘사 없이 애정 표현·둘만의 분위기·편안함·친밀한 대화를 다루며 가족·전 연인·연봉·계좌 정보는 묻지 않습니다. 불편하면 무료로 건너뛸 수 있으며 작성한 답은 지워지고, 다음 질문 시각과 이미 사용한 재화는 유지됩니다.

1. 각자 자기 이름을 선택해 답변합니다.
2. 제출한 답변은 작성자에게도 바로 잠깁니다.
3. 두 답변이 모두 모이면 각자 공개에 동의합니다.
4. 두 사람의 동의가 모두 저장된 뒤에만 답변이 공개됩니다.

로그인이 없는 구조이므로 이름 선택과 잠금은 커플끼리 사용하는 화면상 확인 절차입니다. 답변 자체를 암호화하거나 사용자를 인증하는 보안 기능은 아닙니다.
